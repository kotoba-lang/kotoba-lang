```sh
brew tap kotoba-lang/kotoba
brew install kotoba
kotoba -e '(+ 1 2)'
```

هاد التعبير كيتبع نفس طريق التجميع المقبول بحال ملف. هادي راحة
compile-and-run، ماشي `eval` حر فوقت التشغيل.

## الخدمة الوحدة

1. ثبّت CLI (Homebrew ولا المثبّت اللي كيتأكد من checksum).
2. `kotoba selfhost check --json` — قبل غير جواب `valid` وقائمة المشاكل
   خاوية.
3. جمّع `hello.kotoba` وقبل غير جواب `emitted`.

الخطوات كاملة: [بدا مع Kotoba](getting-started.md).

## هاد الشي ماشي

- النشر المستضاف اللي كيتخلّص عليه **ما حيّ**. `kotoba deploy` اليوم ماشي
  نظير Deno Deploy تقدر تشريه.
- Kotoba على شكل Clojure؛ ماشي وعد بأن Clojure على JVM ولا ClojureScript
  كيفما كانو غادي يخدمو بلا تغيير.
- هاد الصفحة ما كتخترعش أرقام GMV ولا تبنّي الزبناء ولا تسريعات عامة.
