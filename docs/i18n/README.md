# Localized GitHub start paths

These pages help a stranger finish **one job** on GitHub: install the Kotoba
CLI and compile a checked program. They are not a translation of every ADR,
stdlib note, or private app repo.

English remains the source of record. Normative meaning stays in the
machine-readable contracts linked from [docs/README.md](../README.md).

## Translation notice

These files are **machine translations**. Native-speaker review is
**unverified**. Code, commands, URLs, identifiers, and HOLD/status sentences
are copied from English and must not be “improved” into new claims.

## Claims that stay exact

- **Language Release URL: HOLD.** `kotoba-lang/kotoba-lang` has no language
  Release URL. CLI tags on [`kotoba-lang/kotoba`](https://github.com/kotoba-lang/kotoba)
  are an implementation binding, not that gate.
- Implementation artifacts, when they exist, are listed at
  <https://github.com/kotoba-lang/kotoba/releases>.
- Hosted billed deploy is **not** live.
- No invented GMV, customer-traction, or universal speedup numbers.

Locale registry: [`locales.edn`](locales.edn).
