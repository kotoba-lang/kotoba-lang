# Kotoba language profile 6 — 0.7.0

Profile 6 makes the machine-readable grammar, surface status, elaboration
identity, and released language profile agree on one version. It also carries
the public callable-contract and bool-typed predicate boundary introduced after
profile 5.

Compatibility notes:

- Profile 5 remains supported but is deprecated on 2026-08-11. Its earliest
  removal date is 2027-02-07.
- Code that used predicate values as integers must migrate explicitly, for
  example from `(+ (zero? x) (pos? x))` to `(if predicate 1 0)` at each numeric
  boundary.
- Public callable contracts must use the profile 6 contract recorded by
  `lang/guest-grammar.edn` and `lang/elaboration-pipeline.edn`.
- This language release does not by itself make an implementation the public
  default. That requires a separately signed implementation envelope binding
  the commit, tree, source root, artifact digests, package contract, profile,
  and conformance result.

The surface-status authority is `lang/surface-status.edn`; the compatibility
and signed-tag policy is `lang/version-policy.edn`; active release signers are
listed separately in `lang/release-trust.edn`.
