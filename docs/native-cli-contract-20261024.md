# Canonical native CLI contract candidate

Owner direction retires CLJK/CLJC/CLJS, SCI/NBB/KBB/Node, JVM and C-host
execution prerequisites. The contract names canonical Kotoba and the adopted
Amu selfhost compiler. It retains all twelve commands, existing flags,
subcommands, operation-specific authority and the Web/Wasm output targets.
The `--runtime` and reader `--target` flags remain, with only canonical
Kotoba admitted; hosted runtime values are explicitly retired.

This is contract cleanup, not completion of the public CLI. The current
launcher and historical CLI authority remain migration inputs until the
complete native replacement, provider/refusal/cleanup tests, target execution,
source locks, required native CI and main readback are qualified. Contract
tier labels and a parsed command list do not establish product execution.

Tracking: AWAI-24 in the Kotoba Labs workspace. Native source resolution and
writer/replay are tracked with AWAI-43; native FS mechanisms with AWAI-52.
